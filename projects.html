MindEasy Therapy

Therapy Booking App

MindEasy Therapy is a full-stack MERN application that helps users discover therapy clinics, filter available services, book different types of therapy sessions, and complete payments through Stripe.

PROBLEM

Finding and booking therapy can involve searching across different clinics, comparing availability and services, and handling payments separately. MindEasy brings that process into one application.

KEY FEATURES

  • Clinic listings created by therapists
  • Individual, couples, and family therapy bookings
  • Filtering by location, availability, facilities, and consultation type
  • Sorting by price and completed therapy sessions
  • User authentication with JWT and bcrypt
  • Stripe payments for appointment bookings

TECH STACK

React Node.js Express MongoDB Tailwind CSS Stripe

Organ Transplant Management App

Hospital Transplant Request Management System

A full-stack MERN application designed to help hospitals manage organ availability and transplant requests. Hospitals can list available organs, request transplants, and track approvals through role-based dashboards.

PROBLEM

Organ transplant coordination involves multiple hospitals, medical records, availability data, and approval workflows. The application brings these processes into one system so hospitals and admins can manage requests more efficiently.

KEY FEATURES

  • Hospitals can register and request available organs
  • Admins can list organs and manage availability
  • Admins can review and approve transplant requests
  • Role-based dashboards for hospitals and administrators
  • Secure authentication using JWT and bcrypt
  • RESTful APIs connecting the frontend and backend

TECH STACK

React Node.js Express MongoDB Tailwind CSS REST API
